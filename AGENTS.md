# Repository instructions

Follow upstream OpenClaw behavior and defaults. Do not add deployment-specific
restrictions or workaround frameworks without an explicit owner request.
Preserve intentional customizations, integrations, credentials, and data;
this is not a blanket instruction to remove everything custom.

This repository is only for the owner's personal installation. Do not build
generic/default configurations or a profile system for other users.
Documentation covers this setup's differences and operations, not upstream
tutorials or historical incidents.
